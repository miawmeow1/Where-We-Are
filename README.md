# 🎵 Where We Are - Interactive Pixel Lyrics Player

Aplikasi web interaktif pemutar lirik lagu dengan estetika *fantasy pixel art* bernuansa pastel, animasi awan & perahu bergerak, serta efek *typing* teks lirik yang disinkronkan secara real-time. Proyek ini dibangun menggunakan **React**, **Vite**, dan **Tailwind CSS**.

---

## ✨ Fitur Utama

- **Estetika Pixel Art & Fantasy**: Tampilan jendela retro pop-up bergaya klasik dipadukan dengan latar belakang kastil dan pemandangan danau bernuansa pastel yang lembut.
- **Efek Ketik Lirik (Typewriter Effect)**: Lirik lagu muncul secara dinamis mengikuti alunan musik.
- **Elemen Dekoratif Dinamis**: Dekorasi bunga, gelembung, dan kilau bintang yang berubah acak di setiap baris lirik.
- **Audio Integration**: Pemutar musik MP3 terintegrasi dengan tombol kontrol *Start Song*.

---

## 🛠️ Teknologi yang Digunakan

- **React** (UI Framework)
- **Vite** (Build Tool & Dev Server)
- **Tailwind CSS** (Styling & CSS Animations)
- **TypeScript / JavaScript**
